# Egressor - Development Guide

## Build & Test Commands

- `npm run compile` - Compile TypeScript
- `npm run test:unit` - Run unit tests (Mocha)
- `npm run test:coverage` - Run tests with coverage report
- `npm run lint` - Run ESLint
- `npm run lint:fix` - Run ESLint with auto-fix

## Architecture

### Core Modules

- `src/config/` - Configuration parsing, validation, and derived config generation
- `src/container/` - Container detection, Docker discovery, and orchestration
- `src/jail/` - httpjail process management and traffic event parsing
- `src/secrets/` - Secretless Broker management and secret storage
- `src/audit/` - Session logging and audit trail
- `src/views/` - VS Code webview (Traffic Panel) with HTML/JS/CSS

### Multi-Container Flow

1. `DockerDiscovery` (src/container/docker-discovery.ts) discovers sibling containers via Docker socket
2. `ContainerOrchestrator` (src/container/setup.ts) maps discovered containers to config, manages per-container httpjail/broker instances
3. Per-container rule files are generated by `httpjail-rules-generator.ts` and `secretless-generator.ts`
4. Traffic and secret events carry `containerId`/`containerName` fields for filtering in the UI

### Config Inheritance

- `containers[].egress: true` inherits top-level rules; an array overrides them
- `containers[].secrets: true` inherits top-level secrets; an array overrides them
- When `containers` field is absent, single-container mode applies (backward compatible)

## Testing

- Tests are in `src/test/` mirroring the source structure
- Uses Mocha + Sinon for mocking
- VS Code integration tests require the Electron test harness (vscode-test)
- Unit tests can run without VS Code via `npm run test:unit`
